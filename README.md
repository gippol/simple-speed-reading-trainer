# Simple Speed Reading Trainer

英文テキストを 1 語ずつハイライトして、指定した WPM(1 分あたりの語数)で読む速読トレーニング用アプリです。`speed-reading.html` 1 ファイルで動作し、ビルドや依存パッケージは不要です。

※このプロジェクトではコード生成にAIを使用しています

## 起動

`speed-reading.html` をブラウザで開くだけです。

## 使い方

1. **テキストを読み込む**(いずれか)
   - 「ファイルを選択」から `.txt` を選ぶ
   - `.txt` をページにドラッグ&ドロップする
   - テキストをコピーして `Ctrl/Cmd+V` で貼り付ける
   - 「貼り付け」ボタンでクリップボードから読み込む(ブラウザが許可しない場合は `Ctrl+V` を使ってください)
2. **WPM を設定する**(50〜1500)。読書中に変更しても、すぐに反映されます。
3. **START** を押すと、単語が 1 語ずつハイライトされます。
4. **STOP** で一時停止、もう一度 **START** で続きから再開します。
5. **RESET** で最初に戻り、タイマーも 0 になります。
6. 最後まで読み終わると、語数・所要時間・実効 WPM が表示されます。

### 単語をクリックして開始位置を変える

- 停止中に単語をクリックすると、その単語がハイライトされます。次の START は、その単語から始まります。
- 読書中にクリックすると、その単語からテンポを数え直します。

### 表示設定

| 項目 | 内容 | 範囲 |
| --- | --- | --- |
| WPM | 読む速さ | 50〜1500 |
| 色 | ハイライトの色 | 任意 |
| 行間 | 本文の行間 | 1〜4 |
| 幅 | 本文の最大幅(px) | 300〜2000 |

設定はブラウザの `localStorage`(キー `srt`)に保存され、次回起動時に復元されます。保存はブラウザごと、オリジンごとです。`file://` で開いた場合と `http://localhost` で開いた場合では、別の設定になります。読み込んだテキストと読書位置は保存されません。

## 注意

- 英語など、空白区切りの言語向けです。日本語の単語分割には対応していません。
- 読み込むテキストは、空白(改行を含む)で単語に分割されます。改行や段落は表示にそのまま保たれます。
